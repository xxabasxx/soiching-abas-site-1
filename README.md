# ABAS SOFT | آزمایشگاه طراحی منبع تغذیه و ماشین‌های الکتریکی

صفحه اصلی دو‌زبانه (فارسی/انگلیسی) با **۱۰ کاربرگ محاسباتی مستقل**:

| خانواده | صفحات | مدل |
|---|---|---|
| منابع سوئیچینگ | input / transformer / switching / output | فلای‌بک ایزوله تک‌خروجی، فرکانس ثابت، **فقط DCM** |
| ترانس هسته‌آهن | ironcore / ironcore-ind | ترانس EI فرکانس شبکه ۵۰/۶۰Hz؛ نسخه صنعتی با ورق Hi-B و ضریب ایمنی بالاتر |
| الکتروموتور | motor / motor-ind | موتور القایی و DC؛ نسخه صنعتی IE3/IE4 بر مبنای IEC 60034 |
| موتور براشلس | bldc / bldc-ind | BLDC/PMSM؛ Kv، Kt، جریان‌ها و سایز ESC — **نسخه آزمایشی (بتا)** |

## معماری

- **صفحه اصلی:** React + Vite + Tailwind؛ همان‌جا بسته ZIP آفلاین ساخته و پیش از دانلود، CRC و سالم‌بودن برگه‌های Excel هر بخش بررسی می‌شود.
- **کاربرگ‌ها:** HTML مستقل در `public/calculations/` با JavaScript خالص؛ بدون سرور، CDN یا فریم‌ورک کار می‌کنند (حتی با `file://`).
- **موتور مشترک (`engine.js`):** هر ردیف محاسباتی یک درخت عبارت است؛ از همان درخت هم مقدار عددی و هم فرمول نمایشی UI و هم **فرمول زنده Excel** (`MAX`, `SQRT`, `SMALL/COUNTIF` برای روندآپ E12 روی برگه Standards) ساخته می‌شود.
- **دامنه وابستگی (`scope`)：** هر بخش فقط ورودی‌ها و روابط موردنیاز خودش را می‌بیند؛ خطای ESR در کاربرگ ترانس، محاسبه فیلتر خروجی را خراب نمی‌کند و بالعکس.

## کنترل اعتبار (واقعی و اجباری)

محاسبات فقط با دکمه «محاسبه گام‌به‌گام» شروع می‌شود. سه سطح کنترل دارد:

1. **دامنه فیلدها:** هر ورودی در بازه min/max خودش؛ ارقام فارسی (`۰-۹`)، عربی (`٠-٩`) و لاتین پذیرفته می‌شوند.
2. **قیود میان‌پارامتری (خطا / توقف کامل):** مثل `vacMax > vacMin`، `ta < tj`، مثبت‌بودن کف باس، `holdCutoff < busMin`، و بودجه افت ESR در پله بار — هر قید فقط در بخش خودش اعمال می‌شود.
3. **کنترل‌های مدل (`issues`):** نقض DCM در بار نامی یا در بودجه توان با تلرانس Lp، عبور شار از سقف طراحی → **خطای سطح مدل** که در UI نمایش داده می‌شود، `modelValid=false` می‌کند و **خروجی Excel/متن/چاپ را بلاک می‌کند**. هشدارها (پرشدگی پنجره، ریپل بیش از بودجه، مسیر حرارتی غیرممکن، چگالی شار نابت برای ورق معمولی، افت مقاومتی BLDC و…) غیرمسدودکننده‌اند اما صریح گزارش می‌شوند.

علاوه بر این، `selfTest()` موتور در اولین اجرای صریح، ۲۲ اتحاد عددی (توازن انرژی، RMS خازن، گردکردن E12، دامنه ارقام، بلاک DCM و…) را راستی‌آزمایی می‌کند؛ نتیجه آن در بخش «منابع و روش محاسبه» هر صفحه نمایش داده می‌شود.

## خروجی‌ها

- **Excel واقعی `.xlsx`** (شش برگه: Inputs با اعتبارسنجی داخلی Excel، Calculations، Dependencies، Checks با معیار PASS/CHECK، References و Standards با جدول E12) — فقط روابط همان بخش، با فرمول زنده و مقدار کش‌شده.
- **گزارش متنی UTF-8** با فرمول‌ها، فرض‌ها و منابع.
- **چاپ A4 افقی** با رنگ‌بندی روشن.
- **پروژه `.abas.json`** شامل ورودی‌ها، نام، یادداشت و زوج `supplyType`/`topology`.

پروژه هر بخش فقط در همان خانواده بارگذاری می‌شود؛ فایل فلای‌بک در صفحه موتور با پیام واضح رد می‌شود. پروژه‌های قدیمی `volta-smps-project` نیز پذیرفته می‌شوند.

## آفلاین و فونت‌ها

«دانلود نسخه آفلاین» در پایین صفحه اصلی، فایل `abas-soft-offline.zip` می‌سازد که **هر ۱۰ کاربرگ**، موتور، سازنده Excel، فونت‌های Vazirmatn و JetBrains Mono (به‌همراه مجوزها) و صفحه شروع مستقل را دارد. ورود مستقیم به `index.html` از روی فایل سیستم نیز به صفحه آفلاین هدایت می‌شود.

## توسعه و تست

```bash
npm install
npm run dev        # توسعه
npm run build      # خروجی dist (صفحه اصلی تک‌فایل + کاربرگ‌ها)
node --test tests/ # ۴۲ آزمون رگرسیون، عددی، Excel، ترجمه و خوانایی
```

## سلب مسئولیت مهندسی

همه نتایج **پیش‌طراحی** هستند. ساخت مدار متصل به برق شهر بدون بازبینی دیتاشیت قطعات، ملاحظات ایمنی (عایقی، creepage/clearance)، تست حرارتی و راستی‌آزمایی روی نمونه واقعی **مجاز نیست**. پیشنهادهای قطعات نقطه شروع جست‌وجو هستند، نه تأیید انتخاب نهایی. ماژول BLDC در وضعیت بتا است و ممکن است خروجی آن نیازمند بازبینی مهندسی باشد.

## منابع محاسباتی

TI SSZTCW6 (طراحی فلای‌بک DCM)، TI SSZTCU9، onsemi AN-4137 (راهنمای فلای‌بک آفلاین و اسنابر RCD) و Power Integrations AN-17 — لینک‌ها داخل هر کاربرگ و در برگه References خروجی Excel هستند.
